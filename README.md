# MSE800 Professional Software Engineering

This repository contains my learning work for **MSE800 Professional Software
Engineering** as part of my Master of Software Engineering studies.

It is a personal workspace for:

- class exercises and practical activities;
- assessment preparation and submissions;
- experiments used to understand software engineering concepts; and
- notes, examples, and code developed throughout the module.

The repository will grow as the module progresses. Each exercise is kept
small and focused so that the implementation, reasoning, and lessons learned
can be reviewed later.


## Learning focus

This repository will support the development of practical skills in:

- professional software development practices;
- programming fundamentals and problem solving;
- version control with Git and GitHub;
- testing, debugging, and code quality;
- software design and maintainability;
- documentation and technical communication; and
- reflection on engineering decisions and lessons learned.~
